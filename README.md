# Demon List GD

Sitio comunitario de Geometry Dash inspirado en Pointercrate y Global Demonlist.

## Publicar con GitHub Pages

1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment → Source**, selecciona **GitHub Actions**.
3. En **Actions**, ejecuta el workflow **Deploy Demon List to GitHub Pages** o espera al siguiente push.
4. GitHub mostrará la URL pública en Settings → Pages y en el deployment del workflow.

## Puntuación inicial

Cada nivel tiene un valor base de 1,000 puntos (los niveles añadidos desde el formulario empiezan con 500). El récord recibe puntos proporcionales al porcentaje: puntos = valor base × progreso / 100. Por eso GuitarHeroStyles aparece con:

- Bloodlust 100%: 1,000 puntos.
- Shardscapes 73%: 730 puntos.
- Total: 1,730 puntos.

Es una fórmula propia de esta comunidad, no una puntuación oficial de Pointercrate ni GDDL.

## Datos y limitaciones

La web guarda los cambios en localStorage del navegador. Los nuevos récords que se registren desde un dispositivo no se sincronizan automáticamente con otros visitantes. Para una clasificación pública colaborativa hace falta conectar una base de datos y añadir validación/moderación de pruebas.
